# ТЕВИРП

Голосовые сообщения доходят только задом наперёд. Хочешь, чтобы тебя поняли — говори наоборот.

Играть: https://mustafin.github.io/tevirp/

- Создаёшь комнату, отправляешь ссылку другу.
- Пишешь фразу — игра показывает перевёртыш, читаешь его вслух и отправляешь.
- «Испорченный телефон»: фраза идёт по цепочке, каждый слышит только предыдущего.

Сервера нет: браузеры соединяются напрямую по WebRTC ([PeerJS](https://peerjs.com), MIT). Комнату держит вкладка того, кто вошёл первым.

Локально: `node server.mjs`, затем http://localhost:8770
